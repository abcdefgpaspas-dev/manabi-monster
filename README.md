# まなびモンスター

小5・小3の姉妹向け学習ゲーム。スマホのホーム画面に追加してアプリとして使う。

- べんきょう：算数・漢字を5問 → 正解1問につき1コイン、全問正解で+2コイン
- ログインボーナス：1日1回 +2コイン
- ガチャ：5コインで1回（10連は50コインでスーパーレア以上1枚確定）
- 出る確率：ノーマル55% / レア28% / スーパーレア12% / ウルトラレア4% / げきレア1%
- シールちょう：全300種（10ぞくせい×30しゅるい）。ダブりは枚数で記録
- そだてる：シールちょうから「あいぼう」を1匹えらんで育てる。べんきょうの正解でコインと経験値が両方入る。おなか・ごきげん・うんちのおせわつき
- しんか：Lv.8／18／30 で、同じぞくせいのまま しゅるいのランクが上がる。しんかした姿はシールちょうにも増える
  - **かんたんには しんかしない**。レベルが届いても、おなか♥3・ごきげん♥3・うんち0（＝ちゃんとおせわできている）まで しんかしない。届くと「からだが あつい…！」と知らせてくれるので、ごはんやそうじをしてあげるとその場でしんかする
  - めやす：べんきょう1回（5問）でだいたい60EXP。1回目のしんかまで約7回（1週間）、2回目まで約31回（1か月）、でんせつまで約82回（3か月）
- たいせん：別のスマホと通信対戦（4けたコード）。交互に問題を解いて攻撃
- こうかん：きょうだい同士（同じスマホ）／ともだち（別のスマホ・4けたコード）

## 1. Firebase（ともだちとの こうかん・たいせん用・約10分）

> **すでに Firebase を作ってある場合も、3. の「ルール」をやり直すこと。**
> 古いルールのままだと こうかん（`trades/`）が「つながらなかったよ」になる。
1. https://console.firebase.google.com を開き「プロジェクトを作成」→ 名前 `manabi-monster`（アナリティクスはオフでOK）
2. 左メニュー「構築」→「Realtime Database」→「データベースを作成」
   - ロケーション：シンガポール（asia-southeast1）
   - 「テストモードで開始」→ 有効にする
3. 「ルール」タブを開き、`database.rules.json` の中身を貼りつけて「公開」
4. ⚙「プロジェクトの設定」→「マイアプリ」の `</>`（ウェブ）→ アプリ名を入れて登録
5. 表示された `firebaseConfig = { ... }` の `{ ... }` 部分を `config.js` の `null` と置きかえる
   （`databaseURL` が入っていることを確認）

## 2. GitHub Pages（公開）
1. GitHubで新しいリポジトリ `manabi-monster` を作成（Public）
2. 「Add file」→「Upload files」でこのフォルダのファイルを全部ドラッグ＆ドロップ → Commit
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 1〜2分後 `https://abcdefgpaspas-dev.github.io/manabi-monster/` で開ける

## ともだちとの こうかん
- 「こうかん」→「ともだちと こうかん」
- 1人が「へやを つくる」→ 4けたのコードを相手に伝える → 相手が入力して「はいる」
- おたがいに あげるシールを えらび、2人とも「これで OK！」を押すと こうかん せいりつ
- ともだちも 同じURLのアプリを使う必要がある

## たいせん
- 「そだてる」→「べつの スマホと たいせん」
- 1人が「へやを つくる」→ 4けたのコードを相手に伝える → 相手が入力して「はいる」
- 交互に自分の学年の問題が出て、正解すると相手にダメージ。HPを先に0にしたほうが勝ち
- 勝ち +20EXP／負け +12EXP（負けても経験値はもらえる）

## 更新するとき
`index.html` を新しいものに差しかえてアップロードするだけ（`config.js` はそのまま）。
コインやシールは各スマホに保存されているので消えない。
